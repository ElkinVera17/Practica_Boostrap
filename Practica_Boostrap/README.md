# My Professional Portfolio - Ranking

## Project Description

Personal website developed as a practice exercise in **Semantic HTML** and **Modern CSS**. The project demonstrates skills in:

- HTML structure with semantic tags (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`)
- Responsive design with **Flexbox** and **media queries**
- Forms with HTML5 validation
- Multimedia (video, audio, iframe)
- Tables, lists, progress, and meters
- Interconnected pages with consistent navigation

The site includes:
- **Homepage** (index.html) - Professional profile and multimedia content
- **Portfolio** (portfolio.html) - A resume with technical skills and learning progress
- **Search** (search.html) - Demonstration of GET form submission
- **Contact** (contact.html) - Contact form and personal information
