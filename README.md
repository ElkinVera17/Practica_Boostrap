# Proyección Profesional | Elking - Tecnologías de la Información

## Nombre del proyecto

**Proyección Profesional a 10 Años - Elking ITIN**

---

##  Descripción general

Este proyecto consiste en una **página web personal** que presenta la proyección profesional y académica del estudiante a 10 años, desarrollada como parte de la asignatura de Fundamentos Web.

### ¿Qué hace la página?

La página permite visualizar de manera organizada y atractiva:

- **Perfil profesional futuro** en el área de redes y ciberseguridad.
- **Metas académicas** como finalizar la carrera ITIN, alcanzar nivel B2 de inglés y especializaciones.
- **Áreas tecnológicas de interés:** redes, ciberseguridad, automatización.
- **Proyectos esperados:** monitoreo de suelo, sistema contable automatizado, monitoreo de red.
- **Carrusel interactivo** mostrando la vida deseada en 10 años (finca, trabajo en redes, entrenamiento, certificaciones).
- **Barras de progreso** que muestran el avance actual en la carrera.

### Contexto académico

Este proyecto representa el **primer acercamiento formal del estudiante al framework Bootstrap**. Anteriormente, todas las páginas del sitio (`index.html`, `buscar.html`, `contacto.html`, `portafolio.html`) fueron desarrolladas únicamente con **HTML semántico y CSS puro**.

El salto a Bootstrap permitió:
- Aprender a utilizar **clases predefinidas** en lugar de escribir CSS desde cero.
- Comprender el sistema de **grid responsivo** de 12 columnas.
- Implementar **componentes listos** como navbar, cards, carrusel y alertas.
- Adoptar el enfoque **Mobile First**.
